# Orion Sandbox - Windows 7 32-bit Edition

## Quick Start Guide

### Prerequisites
- **Windows 7** (32-bit or 64-bit)
- **Python 3.8** (32-bit) - Download from: https://www.python.org/downloads/release/python-3810/

### Installation Steps

1. **Download Python 3.8 (32-bit)**
   - Visit: https://www.python.org/downloads/release/python-3810/
   - Download: `Windows x86 Installer`
   - Run the installer
   - **IMPORTANT**: Check the box "Add Python to PATH" during installation
   - Click "Install Now"

2. **Extract Game Files**
   - Extract this folder to a location like `C:\Users\YourName\Desktop\OrionSandbox`

3. **Run Installation**
   - Double-click `install.bat`
   - Wait for it to finish
   - Press any key when done

4. **Play the Game**
   - Double-click `play.bat`
   - Game window should open
   - Enjoy!

- **WASD** - Move character

## Troubleshooting

### "Python not found"
- Make sure Python 3.8 is installed
- Reinstall Python and check "Add Python to PATH"
- Restart your computer after installing Python

### "pygame not found" or installer crashes
- Try running `install.bat` again
- Make sure you have internet connection
- Try updating Windows 7:
  - Settings → Windows Update
  - Install ALL updates
  - Restart computer

### Game runs slowly
- Close other programs
- Windows 7 32-bit has limited resources
- Game is optimized for this configuration

### Game won't start
1. Run `install.bat` again
2. Make sure Python 3.8 (32-bit) is installed
3. Check that internet is working (for initial setup)
